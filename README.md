# ATLAS YOLU - Akıllı Ulaşım Projesi

Bu proje, afet anlarında (deprem vb.) trafik yoğunluğunu azaltmak için geliştirilen akıllı ulaşım sistemini içermektedir.

## 🚦 Projenin Amacı
Afet durumlarında acil tahliye yollarının otomatik olarak açılması ve trafik akışının akıllı sistemlerle yönetilmesini sağlamak.

## 🧠 Kullanılan Teknolojiler
- Python
- Sensör sistemleri (deprem algılama)
- Akıllı trafik ışıkları
- Görüntü işleme (gelecek aşama)
